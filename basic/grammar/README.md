# C语言基础语法（C Basic Grammar）
> 本文件夹存放**C语言入门阶段的基础语法练习代码**，按知识点分类、编号整理，每个文件为独立可运行的示例，用于系统学习C语言核心语法，适配算法学习与简历展示。

---

## 📁 文件清单（按学习顺序排序）
| 文件名 | 对应知识点 | 功能说明 |
|--------|------------|----------|
| `01_data_type.c` | 数据类型、变量、全局/局部变量 | 数据类型大小打印、变量作用域测试、两数求和示例 |
| `02_const_define.c` | 常量定义 | `const`常属性变量、`#define`宏定义的使用与区别 |
| `03_enum.c` | 枚举类型 | 枚举类型的定义、枚举常量的默认值打印 |
| `04_string_array.c` | 字符数组、字符串 | 字符数组与字符串的区别、`strlen`长度计算 |
| `05_simple_print.c` | 基础打印 | `printf`基础输出示例 |
| `06_if_branch.c` | 分支语句 | `if-else`分支逻辑的交互示例 |
| `07_while_loop.c` | 循环语句 | `while`循环的基础使用、循环计数示例 |
| `08_scanf_eof.c` | 输入循环 | `scanf`循环读取、`EOF`结束输入的用法 |
| `09_function_add.c` | 函数基础 | 自定义加法函数、函数调用与传参 |
| `10_array_traverse.c` | 数组基础 | 数组定义、`while`循环遍历数组元素 |
| `11_ternary_operator.c` | 三目运算符 | 三目运算符实现两数比较 |
| `12_static_variable.c` | 静态变量 | `static`修饰局部变量的生命周期特性 |
| `13_struct_basic.c` | 结构体 | 结构体定义、结构体变量的初始化与访问 |
| `14_function_max.c` | 函数进阶 | 自定义最大值函数、三目运算符优化 |
| `15_pointer_basic1.c` | 指针基础1 | 指针的定义、地址访问、解引用操作 |
| `16_pointer_basic2.c` | 指针基础2 | 指针间接修改变量值、指针与变量的关系 |
| `17_scanf_format.c` | 格式化输入 | `scanf`自定义格式（分号、逗号分隔）的输入输出 |
| `18_hex_octal_sum.c` | 进制转换 | 十六进制、八进制输入与十进制求和 |
