## 📁 各模块核心说明
### 1️⃣ `basic/` - 基础核心模块
包含C语言入门必备知识，是算法竞赛的基石。
- **grammar/**：数据类型、常量、枚举、字符串、结构体、指针等基础语法
- **loop/**：分支语句(if/switch)、循环语句(for/while)、暴力枚举基础
- **recursion/**：递归思想、DFS入门、字符串递归、子集生成
- **dp/**：动态规划入门（方格路径计数）
- **array/**：数组定义、遍历、查找
- **sort/**：经典排序算法（冒泡/选择/插入等）

### 2️⃣ `luogu/` - 洛谷官方题库
- 收录**洛谷原题**，文件名严格标注题号（如 `P1706_全排列问题.c`）
- 代码可直接提交评测，是算法入门的首选题库

### 3️⃣ `lanqiao/` - 蓝桥杯专项
- `baoli/`：蓝桥杯高频题型，暴力枚举、模拟、数学推导
- 适配蓝桥杯竞赛规则，重点练习暴力与贪心思想

### 4️⃣ `math/` - 数学 & 数论算法
- 收录数论基础（GCD、快速幂等）、数学思维题
- 是算法竞赛的核心考点模块

### 5️⃣ `LeetCode/` - LeetCode 练习
- 经典算法题练习，用于提升逻辑与代码规范

1. **编译运行**：每个 `.c` 文件均可独立编译运行（推荐 GCC 编译器）
   - 命令示例：`gcc 01_gcd_recursion.c -o gcd && ./gcd`

3. **提交规范**：所有代码注释清晰，变量命名语义化，符合C语言工程规范
